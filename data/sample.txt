RAG Agent 脚手架使用说明（示例知识库文档）

本脚手架演示如何用 LangGraph 构建一个「检索增强 + 工具调用」的智能体。

核心组件：
1. 检索（RAG）：使用 FAISS 本地向量库，把 data/ 目录下的 .txt 文档切分、向量化后持久化。运行时通过 retrieve 工具按需检索相关片段。
2. 工具调用（Agent）：LLM 以 ReAct 方式决定何时调用工具。本脚手架默认提供两个工具——retrieve（检索知识库）与 calculator（算术计算），可自行扩展。
3. 编排（LangGraph）：用 StateGraph 串联 agent 节点与 tools 节点，形成「思考 -> 调用工具 -> 再思考」的循环，直到 LLM 给出最终回答。

适用场景：
- 内部文档问答（IT/HR/产品手册）
- 需要结合私有资料与外部工具的多步任务
- 作为更复杂多智能体系统的检索子模块
